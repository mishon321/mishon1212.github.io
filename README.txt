CAMPUS TEACHING POINT WEBSITE
=============================

Upload instructions:
1. Open https://app.netlify.com/drop/
2. Sign in or create a Netlify account.
3. Upload this ZIP file (or unzip it and upload the folder containing index.html).
4. Netlify will publish the website and provide a public URL.

Important current limitations:
- The logo is embedded in index.html.
- Teacher photos are not included in the uploaded HTML; teacher names and qualifications are displayed.
- The admission form currently stores submissions only in the visitor's browser (localStorage). It does NOT send applications to the institute/admin.
- The result lookup is a demo; no results database is connected.
- There is no secure Admin Panel or server/database yet.
